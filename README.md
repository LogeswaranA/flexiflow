**flexiflow** is a hybrid agentic framework for building scalable, multimodal AI systems. It seamlessly combines **graph-based orchestration** for complex, stateful workflows with **event-driven execution** for high-concurrency tasks, making it versatile for both prototyping and production use cases.

Whether you're automating enterprise processes, creating intelligent chatbots, or building research pipelines, `flexiflow` offers a flexible, developer-friendly platform to bring your ideas to life.

---

## 🚀 Why flexiflow?

In a crowded landscape of agentic frameworks like Agno, LangGraph, and CrewAI, `flexiflow` stands out by addressing key pain points:

- **Hybrid Architecture**: Dynamically switches between graph-based (for precise, dependency-driven workflows) and event-driven (for high-throughput, independent tasks) modes.
- **Extensibility**: Modular design with pluggable tools, shared memory, and support for multimodal inputs (text, images, and more planned).
- **Developer-Friendly**: Intuitive APIs, clear documentation, and planned visual tools (e.g., browser-based IDE).
- **Ethical AI**: Includes a stub for ethical guardrails (bias detection, privacy preservation).
- **Open-Source**: Built for the community, `flexiflow` welcomes contributions to shape the future of agentic AI.

---

## ✨ Features

- **Hybrid Workflow Engine** – Graph-based for stateful logic, event-driven for concurrent tasks.
- **Shared Memory** – Persistent and efficient memory layer for agent collaboration.
- **Pluggable Tools** – Modular registry for APIs and custom tools.
- **Multimodal Support** – Text support now; image, audio, etc. planned.
- **Ethical Guardrails** – Stubs in place for privacy/bias checks.
- **Observability** – Basic logging; FastAPI dashboard in roadmap.
